# 產品邊界

PartsRadarTW 是一個以原價屋資料為唯一來源的電腦零組件價格查詢網站，目標是把原價屋既有商品與價格資料整理成更容易搜尋、瀏覽、篩選與掃描價格的介面。

本專案不取代原價屋的購買流程，也不做跨網站比價。第一版先把查詢網站與資料基礎做好，個人化與通知功能留到資料流穩定後再評估。

## 第一版範圍

第一版服務對象是想快速查詢台灣電腦零組件價格的使用者。

包含：

- 商品關鍵字搜尋。
- 商品分類瀏覽。
- 價格排序與基本篩選。
- 商品列表頁。
- 商品詳細頁。
- 商品名稱、分類、價格與資料更新時間顯示。
- 原價屋資料來源說明與原始頁面連結。

## 資料來源

本專案只使用原價屋公開商品資料，包含公開頁面可取得的商品名稱、分類、價格、更新時間與可穩定整理的商品資訊。

## 明確不做的功能

第一版不包含：

- Discord bot。
- 使用者帳號。
- 個人價格提醒。
- 收藏清單。
- 購物車、下單、自動購買或庫存搶購。
- 多資料來源整合。
- 原價屋以外的價格比較。
- 其他硬體通路或比價網站資料。
- 使用者自行上傳的價格資料。
- 後台管理介面。
- 商品評價或留言。
- 商品推薦演算法。
- 電腦菜單產生器。
- 零組件相容性檢查。

以上功能若未來要加入，必須先另行建立規劃文件並重新確認產品邊界。

## 後續功能

價格歷史圖表、價格歷史查詢頁面、個人提醒與 Discord bot 都屬於後續擴充功能，不屬於第一版網站的必要條件。

後續功能的前提是資料流已足夠穩定，可以可靠辨識商品、更新價格並追蹤價格變化。
