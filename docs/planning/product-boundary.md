# 產品邊界

PartsRadarTW 是一個以原價屋資料為唯一來源的電腦零組件價格查詢網站，目標是把原價屋既有商品與價格資料整理成更容易搜尋、瀏覽、篩選與掃描價格的介面。

本專案不取代原價屋的購買流程，也不做跨網站比價。第一版與第二版先把 accountless 查詢網站與資料基礎做好；第三版已另行確認可用 Discord bot 提供有限度的個人目標價提醒與個人價格變動摘要，但網站本身仍不建立帳號系統。

## 第一版範圍

第一版服務對象是想快速查詢台灣電腦零組件價格的使用者。

包含：

- 商品關鍵字搜尋。
- 商品分類瀏覽。
- 價格排序與基本篩選。
- 商品列表頁。
- 商品詳細頁。
- 商品主要圖片、名稱、分類、價格與資料更新時間顯示。
- 原價屋資料來源說明與原始頁面連結。

## 資料來源

本專案只使用原價屋公開商品資料，包含公開頁面可取得的商品名稱、主要商品圖片、分類、價格、更新時間與可穩定整理的商品資訊。

商品圖片是第一版資料需求，不只是 UI 裝飾。若原價屋來源頁無法穩定取得主要商品圖片，應標示為資料完整性風險並追蹤來源穩定性，不應靜默退回無圖片版本。

## 價格資料定位

價格歷史與近期價格變動對使用者有意義，因為它們能協助判斷目前價格是否偏高、近期是否大幅變動，以及配單中的商品是否需要重新確認。

這不等於網站帳號化價格追蹤。網站仍維持 accountless；第三版 Discord bot 可用 Discord user id 建立低成本個人通知，但必須處理退訂、防濫用、通知頻率、去重與資料新鮮度邊界。

## 明確不做的功能

第一版不包含：

- 個人化或互動式 Discord bot，例如查詢指令、私訊、帳號綁定、Discord 內保存配單或個人價格通知。
- 使用者帳號。
- 個人化價格追蹤、商品訂閱、到價通知或個人價格提醒。
- 收藏清單、追蹤清單或 watchlist。
- 購物車、下單或自動購買。
- 多資料來源整合。
- 原價屋以外的價格比較。
- 其他硬體通路或比價網站資料。
- 使用者自行上傳的價格資料。
- 後台管理介面。
- 商品評價或留言。
- 商品推薦演算法。
- 電腦菜單產生器。
- 零組件相容性檢查。

以上功能若未來要加入，必須先另行建立規劃文件並重新確認產品邊界。

## 後續功能

第二版功能以價格歷史、價格變動探索、商品連結健康檢查、正常瀏覽限流調整、原價屋分類擴充、配單與 Excel 匯出為主；詳細範圍以 [第二版 Roadmap](v2-roadmap.md) 為準。

第三版功能以商品分享 / Open Graph、Discord webhook 公開變價廣播、Discord 管理者告警、Discord bot 個人目標價提醒、Discord bot 個人價格變動摘要、內網 ops status page、外部監控與公開流量成長硬化為主；詳細範圍與非目標以 [第三版 Roadmap](v3-roadmap.md) 為準。

後續功能的前提是資料流已足夠穩定，可以可靠辨識商品、更新價格並呈現價格變化。若未來要突破 Roadmap 非目標，必須另行建立產品與資安規劃。
